## 设计决议记录

### 2026-11-08：节点工作台方案弃用（对应远端 PR #23，不合并）

- 结论：**不合并，方向弃用**。原因是 UI 设计问题：单卡片堆叠的参数面与控件
  过多、排布失衡，15 类节点全部工作台化后超出轻卡片路线的视觉承载力。
- main 现行路线确认为正确基线：design 18 的内容自适应轻卡片（每卡单一主控 +
  观测缩略）+ 三点详情浮层 + 右侧栏 inspector 的三层分工。
- 该方案的历史实现不作为任何后续工作的参考基线。
- 记录教训：卡片参数面扩张的硬约束是「每卡 ≤1 个主控 + 只读观测」；全参数
  编辑一律留在 inspector。密度优先于功能完备。

## 从节点工作台方案蒸馏的待办（设计条目，暂不排期）

> 只记方向，不记实现。逐条实施前需各自补设计对齐与验收口径。

1. **卡上主控延长线**：为参数面小的节点评估把主控放上卡片的收益（维持每卡
   ≤1 个主控约束），候选如 EQ 的频率/增益；逐节点单独评估，不做批量方案。
2. **精确数值输入语义**：inspector 数值字段统一「Enter / 失焦提交、非法输入
   保留并提示、未改动不回写」的编辑语义（当前仅部分字段具备）。
3. **会话内 WAV 录制 UI**：Recorder 节点的录制启停、编码选择与剩余容量提示
   （PRD §5.6 已规划 Recorder 节点，此条补 UI 侧需求；service 持有录制生命
   周期，与图启停独立）。
4. **观测真实性围栏**：频谱/电平类观测区分「候选配置 / 运行配置」；停止、
   过期或无发布者时清空展示，不以冻结的最后画面冒充当前读数。
5. **静态曲线调参**：节点卡片缩略的 EQ 拖点已具备（详情浮层已退役，见上
   方决议）；是否为压缩器等增加同类静态曲线交互，按需评估。
