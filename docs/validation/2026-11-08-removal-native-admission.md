## Authority and lifetime

`native-admission.ps1` associates the original controller, actual writer
FileStream/SafeFileHandle, native C# trace owner, managed session and task owner
through a ConditionalWeakTable. A copied object, detached handle/name tuple or
Reviewed/NativeApproved boolean cannot acquire that association. Construction
and dot-source do not dispatch native operations. The production script-set
manifest now requires all25actual production libraries, including admission.

Each birth operation revalidates the original root, finite deadline, immutable
source/input pins and actual target readiness. It rechecks deadline/errors and
the original BEFORE age after synchronous hashing returns. Final registration,
RunEx and post-query probe-admission gates precede their actual dispatch or
acknowledgement. No hard filesystem/API deadline is claimed.

Task registration seals the exact original scheduler/folder/definition before
the one create-only COM call. Its returned task reference/XML are retained
separately before RegistrationKnown. Completion sealing does not require
renewed birth freshness; subsequent RunEx does. Unknown COM returns never
authorize registration retries, name adoption or task absence.

STOP uses the exact successful StartTrace owner, handle and GUID. Its lifetime
authority does not require a still-fresh BEFORE, Explorer liveness or unchanged
input-file contents. It does require the original live writer and resource
associations. Failed enable/readback does not forfeit cleanup of a self-created
trace, and no by-name fallback is introduced.

StartAttempted remains one-shot; a separate read-only StartDispatchAttempted
bit distinguishes refusal before API dispatch from a call with unknown output.
Only the latter remains unresolved. Neither path invents a native status or
permits a retry. Decode steps similarly retain typed dispatch intent: an
explicit false with no tool owner is known-not-dispatched, whereas missing,
nonboolean or true with no owner remains unresolved.

Closed decode tools/package/probe/symbol pins must match the original static
input snapshot, not a new set attached after STOP. Each request must be the
original pending step and have exact canonical executable/hash/argv/output/
limits. Task retirement independently recomputes the whole worker/probe/task
terminal state, verifies the original task COM references/XML and requires
readback-hashed finish or abort evidence. Direct public cleanup cannot bypass
the composed finish checks or erase changed full-argv provenance.
