## Coordinate and numerical contract

`scripts/vad-src-phase.py` queries **successful FIR output index versus
reset-scoped pushed-input center**. Playback input includes starvation fill;
microphone output includes FIR frames before any drop. Neither coordinate is
a native packet frontier. Engine transferred frames and carrier frames use
their existing direction-specific rates; they are not interchangeable.

For output offset `k`, the relative center interval is:

```text
fraction_before + k * processing_step +/- k * 2^-32 input frames
```

The integer `next_input_frame` origin stays separate, including beyond2^53.
Fractions and applied steps are converted to exact rationals of their imported
binary64 values, never a fitted float origin or rounded nominal ratio. The
reported step is captured after servo update; `before.step` can legitimately
differ and is not used instead. `after.step` must match the applied value.

The fixed bound follows the current production arithmetic: FIR capacity is
at most2^20, local position before a successful output is below capacity and
the admitted step is below50. The positive binary64 sum is below2^21, giving
addition error at most2^-33 input frames. Integer discard and fractional split
are exact in that local range;2^-32 per output is a conservative fixed bound.
It is not adjusted to observed residuals. Callback Engine/input/output counts
are capped at2^20; actual step must also match direction/sample-rate nominal
within the existing2000-ppm authority plus fixed1e-12 product slack. Unsupported
counts/rates or after-centers outside the bound refuse, not widen the interval.
This reasoning is pinned to the current resampler; a changed implementation
requires reviewing the contract rather than silently reusing it.

Each callback checks schema-validated unsaturated cursors, sequence, prior
cursor identity, Engine timeline/rate continuity, transport/reset epochs,
actual applied step, full Engine transfer, direction-specific pushed/produced/
carrier frontiers and available FIR lookahead. No step, unknown cursor,
starvation, XRUN, discontinuity, explicit mute or reset/fence change is a barrier.
Saturation remains sticky for that boundary even if a later imported cursor
clears its flag or changes generation. Each boundary is independent; no
cross-node atomicity or upstream cleanliness follows from a local mapping.

After a barrier, future mapping requires a wholly new clean FIR support window.
The32 taps span `floor(center)-15 .. floor(center)+16`; a query touching startup
padding or pre-barrier pushed frames refuses. No interpolation crosses a
barrier, even when the numeric after-center happens to be continuous. Clean
segments may resume after sufficient newly pushed input, but never retroactively
validate refused queries or prove continuous waveform quality. An unfed source
can feed silence into an otherwise locally consistent downstream sink.

## Interface and bounded integration

```text
python scripts/vad-src-phase.py --summary RUN/src-trace.json --chunks RUN/src-trace.chunks.jsonl --queries RUN/phase-queries.json --output RUN/phase-report.json
python scripts/tests/vad-src-phase.tests.py
```

The create-new query JSON has exact fields:

```json
{"schema_version":1,"owner_generation":7,"queries":[{"node":"NodeId(0)","kind":"virtual_playback","sequence":64,"output_offset":16}]}
```

At most256 unique queries and256 KiB query bytes are accepted, with the existing
archive byte/boundary caps. Queries index callback and successful FIR output
offset, not always Engine frame offset; microphone resampling makes that
distinction essential. The reader retains one prior checkpoint per boundary,
bounded query/results tables and no lifetime PCM/coordinate array. Lookup is
by callback rather than scanning every query per sample or callback.

The strict archive reader gains only an optional checkpoint observer. Its
default output/semantics are unchanged. The phase CLI keeps observer results
private until full terminal/count/hash readback succeeds with matching owner
and complete scalar coverage. Truncated, contradictory or incomplete archives
cannot release a phase report. Valid complete archives with refused queries
retain a diagnostic and exit1. Existing reports and input files are never
overwritten. SHA-256 describes consumed bytes, not authenticated acquisition,
file immutability or power-loss durability.

All reports unconditionally retain `qualified=false`, `native_execution=false`,
unknown source origin and not-evaluated waveform quality/physical delay. A
mapped center is an imported scalar arithmetic/support result, not issuance
of a NativeObservation handle or proof that clean native audio was acquired.
