# Retained Process Evaluation And Apply Implementation Plan

**Goal:** Connect closed native predecessor evaluation to an explicit desktop
Apply without promoting diagnostic replay into measured admission.

**Architecture:** Continue the authorized S1-S3 implementation. The pinned
collector also retains its original delivery/whole-wake observers. After host
join, independently retain final typed measured delivery or its refusal.
Background evaluation first applies conservative whole-wake admission, then
replays the exact admitted options. Only native-origin, no-violation evidence
can mint an immutable session-local candidate. Explicit Apply is accepted only
while stopped against the exact retained predecessor/document/graph/settings.
Use the existing measured-profile owner preparation and activation confirmation.

**Alternatives:** Live measured Apply already works but cannot consume the
stopped predecessor. Reusing declared diagnostic bounds would lose whole-drain
and whole-wake requirements. Reacquiring a registry at retirement can select a
different native owner. Neither is an acceptable shortcut.

## Constraints

- No VM/native audio/device/driver/deployment operations or production defaults.
- Retain observation storage only, not audio resources or unique writers.
- Final measurement occurs after joins and existing cleanup/generation checks;
  missing/inconsistent measured history refuses Apply, not diagnostic replay.
- No JSON/native trust promotion. Opaque candidates have private fields and no
  Deserialize. Mutable public reports cannot mint or modify candidates.
- One candidate/worker/predecessor, exact Arc/draft/policy fences. Only stopped
  Idle with no owner/cleanup/pending work can Apply a retained candidate.
- Service independently rechecks document, graph revision, Process identity,
  audio/transport/profile, predecessor cleanup and typed admission before setting
  desired state. New native preparation still checks actual whole-wake demand.
- No allocation/blocking on RT; no enlarged histories or buffer defaults.
- Preserve unrelated gate.log; scoped atomic commits, prompt push/full SHA check.
