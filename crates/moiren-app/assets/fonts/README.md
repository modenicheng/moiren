# Inter

The unmodified Inter variable font is embedded and registered with the application text system. Controls use the Inter family at weights 500 and 600.

- Upstream: [Inter](https://github.com/rsms/inter).
- Version: 3.019, git-0a5106e0b, copied from the installed Inter distribution.
- SHA256: `b9a8e5e213977665be2a56db66945a16c686da3d9861af1e7851322cf15495ea`.
- License: SIL Open Font License 1.1, included in `OFL-Inter.txt` from the [Google Fonts Inter distribution](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt).

Embedding the font keeps component geometry independent of installed fonts and does not install or alter system fonts.
